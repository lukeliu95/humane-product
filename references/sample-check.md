# 真实样本验证

只有结果取决于数据的功能才做：搜索、筛选、匹配、导入、识别（比如读单据照片）、AI 生成。

"能做"不是证据，拿真实数据跑出来的才是。

1. 取 5～10 条真实样本。去掉个人信息；真实客户资料放在 git 之外。
2. 每条看三件事：
   - 条件查得到吗？数据里真有这个字段、这个值吗？
   - 结果能用吗？用户会直接拿去用，还是要大改？
   - 错了用户发现得了吗？有没有依据可以核对？
3. 查不到的条件，和需求方商量换成能查到的说法，写进意图卡的变更记录。
4. 再跑一次，把"N 条里能用 M 条"写进 task-tests.md。
5. 能用率的门槛由负责人在意图卡里定。没定时只报数字，不自己判过关，也不自己扩大规模。

样本量和能用率门槛目前都没有团队定的数字，不要自己编一个当标准。
